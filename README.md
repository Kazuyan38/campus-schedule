# Campus Schedule — 時間割

クォーター制（Q1〜Q4）・1〜5限・月〜金に対応した、ダークテーマの大学時間割アプリ。試験勉強のスケジュール管理も兼ねる。単一 HTML・外部依存なし・オフライン動作。

公開URL: https://kazuyan38.github.io/campus-schedule/

## できること
- 時間割グリッド（今日の列・現在の時限をハイライト）と、全情報を並べた一覧ビュー
- 授業ごとに 授業名 / 教室 / 先生 / 教科書 / 評価基準（項目と割合・補足）/ 単位 / シラバスURL / メモ / 色
- 1つの授業に複数のクォーター・複数のコマを設定可能（重複は警告表示）
- NOW / NEXT カード（授業中なら残り時間、次の授業まで何分か）
- 4年分の管理：学年タブ（入学年度から1年〜4年、5・6年にも変更可）で年度ごとの時間割を切替
- 成績入力（S/A/B/C/F・秀/優/良/可/不可 などを設定で切替、合格/不合格/取消/履修中）
- 単位・成績ダッシュボード：取得単位／取得予定単位／卒業要件（既定124）までの残り、通算・学年別 GPA、科目区分別の要件達成、成績分布
- 履修一覧：今期／この学年／4年間すべて（検索付き）
- 欠席カウンター：NOWカードから欠席・遅刻をワンタップ記録、「あと何回休めるか」を表示。上限1回前で橙、到達で赤（1/3・1/4・1/5ルール、遅刻換算、授業ごとの上書き・オフに対応）
- 時間割外の授業（集中講義・オンデマンド）にも対応
- **スマホ最優先の作り**（iPhone Safari / ホーム画面アプリを基準に調整）
  - 週間 / 1日の表示切替。1日表示は大きな文字で全コマを縦に並べ、その日の試験・勉強タスクも出す。週間表示の曜日見出しをタップするとその曜日の1日表示へ
  - 左右スワイプで、週間・履修一覧はクォーター、1日表示は曜日を切替（画面の左右端は iOS の戻る操作に譲る）
  - 年とクォーターのタブを1行にまとめ、NOW/NEXTカードも圧縮。時間割の1〜5限が1画面（iPhone 14/15 級）に収まる
  - シートは見出しを下へ引いて閉じられる。ソフトキーボードが出ても保存ボタンがキーボードの上に残る
  - 主要なボタンは高さ42〜44px以上。ホーム画面用アイコンを内蔵（`apple-touch-icon`）
- **試験対策タブ**（下部ナビ4つ目）：試験・小テスト・レポートを授業に紐づけて登録し、勉強スケジュールを管理
  - 試験範囲を1行1項目で書くと、今日〜試験前日に勉強タスクを自動で割り振り（前日は総復習、他の試験日は回避）。完了済み・手動タスクを残したまま作り直せる
  - 次の試験までのカウントダウン、目標勉強時間に対する進み具合（ワンタップで＋15/30/60分を記録、完了タスクの時間も加算）
  - 今日やること（持ち越し分を含む）、14日間の計画ストリップ（予定と実績の棒グラフ、試験日マーカー）
  - 授業の評価基準から「この試験は成績の何%か」を自動表示。授業の詳細画面からも試験を追加・確認できる
  - 7日以内の試験数をタブにバッジ表示。終了した試験には結果（点数・評価）を記録
- 共有リンクで端末間同期（データはURL内に圧縮して格納。サーバーには送信しない）、JSON書き出し・読み込み

## ホーム画面への追加（iPhone）
Safari で開き、共有ボタン →「ホーム画面に追加」→「Webアプリとして開く」をオンにして「追加」。
Safari とホーム画面アプリは保存領域が別なので、追加の前に「共有・同期」から共有リンクかJSONを控えておく。

|---|---|
| 1 | 9:00–10:30 |

| 4 | 14:40–16:10 |

変更は `index.html` 冒頭の `PERIODS` 定数を編集する。

## データ
ブラウザの localStorage（キー `campus-schedule/v1`）に保存。リポジトリには授業データを含まない。

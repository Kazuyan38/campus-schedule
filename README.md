# Campus Schedule — 時間割

クォーター制（Q1〜Q4）・1〜5限・月〜金に対応した、ダークテーマの大学時間割アプリ。試験勉強のスケジュール管理も兼ねる。単一 HTML・外部依存なし・オフライン動作。

公開URL: https://kazuyan38.github.io/campus-schedule/

## できること
- 時間割グリッド（今日の列・現在の時限をハイライト）と、全情報を並べた一覧ビュー
- 授業ごとに 授業名 / 教室 / 先生 / 教科書 / 評価基準（項目と割合・補足）/ 単位 / シラバスURL / メモ / 色
- 1つの授業に複数のクォーター・複数のコマを設定可能（重複は警告表示）
- NOW / NEXT カード（授業中なら残り時間、次の授業まで何分か）
- 4年分の管理：学年タブ（入学年度から1年〜4年、5・6年にも変更可）で年度ごとの時間割を切替
- **成績**：評語 A（秀）・B（優）・C（良）・D（可）・F（不可）・N（単位認定）・G（合格）・H（不合格）・Y（失格）。評価点（A 90〜100／B 80〜89／C 70〜79／D 60〜69／F 59以下）を入力すると評語を自動判定。単位は A・B・C・D・N・G が合格、F・H・Y が不合格。GP は A=4.0・B=3.0・C=2.0・D=1.0・F=0・Y=0 で、N・G・H は GPA に算入しない。基準表は設定画面に掲載。旧版の成績（P=合格・N=不合格）は初回読み込み時に G・H へ自動で移行
- 単位・成績ダッシュボード：取得単位／取得予定単位／卒業要件（既定128）までの残り、通算・学年別 GPA、卒業要件の区分別の達成状況（図と表）、成績分布
- **卒業要件（128単位）と区分**：全学教育科目 36 ＋ 専門教育科目 92（学部共通専門科目 10・基幹科目 12・地域課題関連分野 4・公共政策関連分野 4・経済・社会関連分野 4・実践科目 14・ゼミナール 12・関連科目〔最低単位なし〕・選択科目 32）を初期設定として内蔵。授業の登録・編集で区分をタップして選ぶと、「単位・成績」の「卒業要件の内訳」に図（区分ごとの幅＝最低単位、塗り＝取得、斜線＝履修予定）と表で集計される。区分名・最低単位は設定で編集でき、「初期設定に戻す」も可能。区分名を変えると授業の区分も追従する
- **学年暦（2026〔令和8〕年度）**：ヘッダーのカレンダーボタンで、月カレンダー（授業日／休み／定期試験期間／履修登録／曜日振替を色分け、日付タップでその日の状態と授業）と日程一覧を表示。第1〜4学期（4/8〜6/10・6/11〜8/7・10/1〜11/30・12/2〜2/9。前期＝第1＋第2、後期＝第3＋第4）、祝日（内閣府の祝日CSVで照合済み）、休講日、曜日振替（7/23→月、10/23→火、11/5→月、1/12→金）、休業（夏・冬・春）、オリエンテーション・入学式、履修登録期間、定期試験期間（その学期で履修が終わる科目だけが試験、他は通常授業）を内蔵。授業日以外は休み。これを次に反映する：①出欠の総授業回数（祝日・休講・振替・試験期間を除いて自動計算。曜日ごとに15〜16回前後になり、例えば前期・後期の月曜はどちらも15回）②NOW/NEXT（休みの日・振替の日を正しく飛ばす／夏休み明けの最初の授業まで案内）③時間割画面の上の日付バナー（今日が休み・振替の日、履修登録期間、試験期間）と今週の例外、定期試験期間の科目の印 ④試験対策タブの次の定期試験期間と、試験フォームの期間ヒント。前期・後期・通年はクォーターのワンタップ設定。学年暦は `index.html` の `CALENDARS` に年度ごとに追加する（登録のない年度は平日を授業日として扱う）
- **進級要件（2年次 → 3年次）**：「単位・成績」画面に専用カード。総取得単位 64 以上（必修科目を含む）／必修3科目（教養セミナー・情報処理演習Ⅰ・新聞で学ぶ経済Ⅱ）／選択科目5つのうち8単位以上（長崎のしまに学ぶ・英語〔必修の英語8科目：英語Ⅰ〜Ⅳ・オーラルコミュニケーションⅠ・Ⅱ・リーディングⅠ・Ⅱから4単位〕・ミクロ経済学入門・マクロ経済学入門・基礎演習4）を、授業名に名称を含む授業から自動で判定し、達成／見込み／未達を表示。未登録の科目はタップで授業登録（名前・単位つき）。新聞で学ぶ経済Ⅱの修得要件（日経TEST 300点）は最高スコアを入力して追跡でき、受験日を試験として登録できる。要件の定義は `index.html` 冒頭の `PROMOTION` 定数
- 入学年度は 2026 年度（4年制）が既定（`ENTRY_YEAR`）
- 履修一覧：今期／この学年／4年間すべて（検索付き）
- 欠席カウンター：NOWカードから欠席・遅刻をワンタップ記録、「あと何回休めるか」を表示。上限1回前で橙、到達で赤（1/3・1/4・1/5ルール、遅刻換算、授業ごとの上書き・オフに対応）
- 時間割外の授業（集中講義・オンデマンド）にも対応
- **スマホ最優先の作り**（iPhone Safari / ホーム画面アプリを基準に調整）
  - 週間 / 1日の表示切替。1日表示は大きな文字で全コマを縦に並べ、その日の試験・勉強タスクも出す。週間表示の曜日見出しをタップするとその曜日の1日表示へ
  - 左右スワイプで、週間・履修一覧はクォーター、1日表示は曜日を切替（画面の左右端は iOS の戻る操作に譲る）
  - 年とクォーターのタブを1行にまとめ、NOW/NEXTカードも圧縮。時間割の1〜5限が1画面（iPhone 14/15 級）に収まる
  - シートは見出しを下へ引いて閉じられる。ソフトキーボードが出ても保存ボタンがキーボードの上に残る
  - 主要なボタンは高さ42〜44px以上。ホーム画面用アイコンを内蔵（`apple-touch-icon`）
- **試験対策タブ**（下部ナビ4つ目）：試験・小テスト・レポートを授業に紐づけて登録し、勉強スケジュールを管理
  - 試験範囲を1行1項目で書くと、今日〜試験前日に勉強タスクを自動で割り振り（前日は総復習、他の試験日は回避）。完了済み・手動タスクを残したまま作り直せる
  - 次の試験までのカウントダウン、目標勉強時間に対する進み具合（ワンタップで＋15/30/60分を記録、完了タスクの時間も加算）
  - 今日やること（持ち越し分を含む）、14日間の計画ストリップ（予定と実績の棒グラフ、試験日マーカー）
  - 授業の評価基準から「この試験は成績の何%か」を自動表示。授業の詳細画面からも試験を追加・確認できる
  - 7日以内の試験数をタブにバッジ表示。終了した試験には結果（点数・評価）を記録
- **アカウントとクラウド同期（任意）**：メールアドレスとパスワードで登録・ログインすると、時間割・成績・試験が自分のアカウントにクラウド保存され、別の端末でも同じデータを使える。**複数人が、それぞれ自分の時間割だけを登録できる**（行レベルセキュリティで他の人のデータは読めず、端末内の控えもアカウントごとに分かれる）。ログインしなければ通信は一切なく、従来どおり端末内だけで使える（ログイン前のデータは、ログイン・ログアウト・アカウント削除のどれでも書き換わらない）。初回は「ログイン前のデータを引き継ぐ」か選べる。自動同期（編集の2秒後・画面を離れるとき・開いたとき・60秒ごと）、編集中のシートは差し替えない、両方が変わったときは競合として選ばせる（選ぶ前に両方を書き出せる）、共有端末向けの「データも消してログアウト」、パスワード再設定、クラウドの記録の削除、アカウントの削除、メールのリンクからのログインは確認を挟む。進級要件カードは、設定で非表示にできる。セットアップは `CLOUD_SETUP.md`
- 共有リンクで端末間同期（データはURL内に圧縮して格納。サーバーには送信しない）、JSON書き出し・読み込み

## ホーム画面への追加（iPhone）
Safari で開き、共有ボタン →「ホーム画面に追加」→「Webアプリとして開く」をオンにして「追加」。
Safari とホーム画面アプリは保存領域が別なので、追加の前に「共有・同期」から共有リンクかJSONを控えておく。

## データ
ブラウザの localStorage に保存。リポジトリには授業データを含まない。

| キー | 内容 |
|---|---|
| `campus-schedule/v1` | ログインしていないときのデータ（従来どおり。ログインしても書き換えない） |
| `campus-schedule/u/<ユーザーID>` | ログイン中のアカウントの、この端末の控え（アカウントごとに別） |
| `campus-schedule/sync/<ユーザーID>` | そのアカウントの同期の状態（版番号・未送信の有無） |
| `campus-schedule/auth` | ログインの資格情報（ログアウトで消える） |
| `campus-schedule/device` | この端末の接続先（Supabase の URL と anon キー）。焼き込み済みなら不要 |

## 開発用（`dev/`・`supabase/`）
| ファイル | 内容 |
|---|---|
| `supabase/schema.sql` | クラウドのテーブルと行レベルセキュリティ（Supabase の SQL Editor で実行） |
| `supabase/admin.sql` | 管理者ページ用の関数と、管理者の登録（`app_admins`）。`schema.sql` の後に実行 |
| `dev/set_cloud.py` | 接続先を `index.html` の既定値に焼き込む（`--clear` で空に戻す） |
| `dev/mock_supabase.py` | Supabase と同じ形で応答する検証用サーバ（`--confirm` でメール確認あり） |
| `dev/cloud_e2e.cjs` | ログイン・同期の自動テスト（`node dev/cloud_e2e.cjs`、Chrome が必要） |
| `dev/admin_e2e.cjs` | 管理者ページの自動テスト（`node dev/admin_e2e.cjs`、Chrome が必要） |

## 管理者ページ（`admin.html`）
公開URLの `/admin.html` を開き、管理者として登録されたアカウントでログインする。人数・直近7日の更新と新規・データ容量・休止までの余裕・利用者一覧（メール・登録日・最終更新・授業数・容量）の確認と、アカウントの削除ができる。

- ページ自体は誰でも開けるが、データは `admin_*` 関数からしか出ず、関数は `app_admins` に載っていない人を `forbidden` で拒否する。
- 時間割の中身（授業名・成績・メモ）は返さない。
- 管理者を足すときは、SQL Editor で `insert into public.app_admins (user_id) select id from auth.users where email = '…';` を実行する。

# Campus Schedule — 時間割

クォーター制（Q1〜Q4）・1〜5限・月〜金に対応した、ダークテーマの大学時間割アプリ。単一 HTML・外部依存なし・オフライン動作。

公開URL: https://kazuyan38.github.io/campus-schedule/

## できること
- 時間割グリッド（今日の列・現在の時限をハイライト）と、全情報を並べた一覧ビュー
- 授業ごとに 授業名 / 教室 / 先生 / 教科書 / 評価基準（項目と割合・補足）/ 単位 / シラバスURL / メモ / 色
- 1つの授業に複数のクォーター・複数のコマを設定可能（重複は警告表示）
- NOW / NEXT カード（授業中なら残り時間、次の授業まで何分か）
- 4年分の管理：学年タブ（入学年度から1年〜4年、5・6年にも変更可）で年度ごとの時間割を切替
- 成績入力（S/A/B/C/F・秀/優/良/可/不可 などを設定で切替、合格/不合格/取消/履修中）
- 単位・成績ダッシュボード：取得単位／取得予定単位／卒業要件（既定124）までの残り、通算・学年別 GPA、科目区分別の要件達成、成績分布
- 履修一覧：今期／この学年／4年間すべて（検索付き）
- 時間割外の授業（集中講義・オンデマンド）にも対応
- 共有リンクで端末間同期（データはURL内に圧縮して格納。サーバーには送信しない）、JSON書き出し・読み込み

## 時限
| 限 | 時間 |
|---|---|
| 1 | 9:00–10:30 |
| 2 | 10:40–12:10 |
| 3 | 13:00–14:30 |
| 4 | 14:40–16:10 |
| 5 | 16:20–17:50 |

変更は `index.html` 冒頭の `PERIODS` 定数を編集する。

## データ
ブラウザの localStorage（キー `campus-schedule/v1`）に保存。リポジトリには授業データを含まない。
